## era 1 · 发展期（0-10 年）——「科研船与殖民地，不是战舰」

**总目标**：基础收支转正、科研起步、吃满可殖民星。社区共识：前期合金是
扩张命脉，舰队只求吓阻；此时建舰 = 用科研换铁皮。

**各相位执行**：

| 相位 | 本时代动作 |
|---|---|
| RELIEF | 反应式补赤字（唯一例外豁免时代） |
| HOUSING | 反应式补住房；白名单 4 级：住房余量 <2 且未达城区上限时可建城区 |
| JOBS | 反应式补岗位；**不建铸造区**（合金需求极低） |
| AMENITIES | 反应式补舒适度 |
| SCIENCE | **主力相位**：研究区白名单放开（不受 era 限制），消费品门生效 |
| MILITARY | **禁止建舰**（发展优先门关闭）；哨站/边境维护照常 |
| ASCENSION | 传统照常推进 |
| WAR | 仅防御姿态；哨站维护、陆战队不征募 |

**建舰四门在本时代的状态**：容量门/能源门/冗余门逻辑在但被发展优先门
短路（`years_passed < 10` 且无威胁）。
**退出条件**：`years_passed >= 10`。

---

## era 2 · 巩固期（10-30 年）——「吓阻舰队 + 经济爬坡」

**总目标**：合金月收入爬坡（社区锚点：约 20 年时 +50/月）；建起吓阻舰队
（容量 30-60%，约 15-40 护卫舰级）；开始专业化分工。

**各相位执行**：

| 相位 | 本时代动作 |
|---|---|
| RELIEF / HOUSING / AMENITIES | 同 era1 |
| JOBS | 白名单 2 级解锁：矿物收入 >0 且合金收入低于爬坡线 → 建铸造区 |
| SCIENCE | 白名单 1 级持续：研究区优先级最高 |
| MILITARY | 建舰四门全开；目标是把容量使用率抬到 30-60% **后停手**（比例控制 P4） |
| ASCENSION | 传统照常 |
| WAR | 仍不主动宣战；边境哨站升级维护 |

**退出条件**：`years_passed >= 30`。

---

## era 3 · 专业化期（30-75 年）——「铸造世界成型，战争成为选项」

**总目标**：专业化星球分工（铸造星/研究星）；舰队换代（驱逐舰/巡洋舰，
容量 60-90%）；满足六条件可打第一场**有限战争**。

**宣战六条件（全满足才宣战，§规格书 4.3）**：

1. `years_passed >= 30`（本时代已满足）
2. 目标国相对军力 < 我方 70%
3. 能源/合金月收入为正且库存达安全垫
4. 目标国不在联邦、其联邦无战争（社区教训：动一个、联邦全反目）
5. 战争目标限割边数系或逼附庸，**不打灭国战**
6. 威胁 ≥3 或已被宣战时豁免 1、3 的库存条

**相位差异**：MILITARY 容量目标抬到 60-90%；WAR 相位按六条件评估宣战；
其余同 era2。

**退出条件**：`years_passed >= 75`。

---

## era 4 · 扩张期（75-150 年）——「满容量常备军 + 有限战争循环」

**总目标**：容量 90-100% 满编常备军；多星系纵深；传统树持续推进；
战争→消化→再战争的循环（每次目标有限，见 era3 条 5）。

**相位差异**：MILITARY 满容量目标；WAR 评估节奏放宽（每 2 年评估一次
而非每年）；ASCENSION 与 WAR 并重（飞升加成直接抬军力）。
其余同 era3。

**退出条件**：`years_passed >= 150`。

---

## era 5 · 危机准备期（150 年+）——「死守咽喉，等天灾」

**总目标**：经济支撑多支满编主力舰队（社区锚点：危机到来前能养多支
满编战列舰队不赤字）；边境咽喉星垒要塞化；**停止对外扩张**（固化边界，
省维护与帝国规模）。

**相位差异**：

| 相位 | 动作 |
|---|---|
| MILITARY | 满容量维持 + 损失补齐（rebuild 优先于 expand） |
| WAR | **仅防御反击**：被宣战或威胁 ≥3 才动；不主动宣战 |
| HOUSING/JOBS | 白名单收紧：只补缺口，不新开城区 |
| 其余 | 维持现状 |

**无退出条件**（终局姿态）。

## 横切规则（全时代生效）

1. **反应式优先**：任何赤字（能源/食物/消费品/住房/岗位/舒适度）出现时，
   对应相位的补救动作**优先于**本手册一切主动扩张（规格书 P2）。
2. **资源冗余线**：所有花销动作走 `overmind_can_afford`（S-1），安全垫见
   规格书 §3；能源收入 ≤0 冻结一切扩军。
3. **威胁例外**：`om_lex_threat >= 3` 时，发展优先门与合金垫可豁免；
   容量门与能源门**永不豁免**（P6）。
4. **嵌套预算**：新增查表逻辑全部走变量+ scripted_trigger，不加深相位
   嵌套（硬约束 ≤5 层）。

## 飞升策略（ASCENSION 相位的路线、传统与天赋查表）

> 来源：Paradox Wiki 飞升天赋页（4.x 四路线 + 危机天赋）、社区实测共识
> （基因速攻 / 合成滚雪球 / 灵能高方差）。用户口语对照：兽飞升=生物/基因、
> 文飞升=灵能（凝聚/领袖/灵能事件流）、武飞升=武力扩张流（危机天赋向）、
> 另有机械系（合成/义体）两条。

### 四大路线一览（怎么选）

| 路线 | 解锁时机 | 强项 | 弱项 | 适合 |
|---|---|---|---|---|
| 生物/基因（兽） | 最早之一（基因裁剪科技） | 人口增长最快、特质自由定制、可专精岗位 | 微管理重、吃社会学研究 | 速攻、人口流（社区实测胜率上限最高） |
| 灵能（文） | 最早（唯心+导师起源开局即有） | 领袖最强、凝聚/科研/稳定、灵能契约 | 高 RNG：关键科技抽取与灵能事件链约 35-40% 成功率，契约可能反噬 | 领袖流、传统流；抽不到理论科技要果断换线 |
| 合成 | 最晚（合成科技+AI 权利） | 岗位产出天花板、领袖不朽、无幸福问题 | 解锁晚、唯心邻国外交惩罚、机器人政策限制 | 滚雪球长跑 |
| 义体 | 早（第一个飞升天赋即可） | 平衡：组装速度+岗位产出+陆军/领袖 | 各项都不是最尖 | 稳健过渡路线 |

### 资格闸门（硬限制，选型前必查 —— 全部可触发器化）

四条有机路线 + 机械路线对**物种/起源/民议/政策**有硬性限制（Wiki 4.x）。
查表前先过四道闸，任何一道不满足即从候选里剔除，**不是降权而是禁选**：

| 闸门 | 判定（触发器） | 结果 |
|---|---|---|
| 物种闸 | `is_machine_empire` / `is_hive_empire` / 有机创始物种 | 机械智能：有机四线全禁，只走机械专属树；蜂巢：灵能禁（特例除外）、合成禁 |
| 起源闸 | `has_origin` | 导师之幕→灵能开局即定；合成繁育→合成锁定；克隆军队→生物需先过事件链；过度调校→生物只能做第 2 天赋；硬重置→义体锁定；自然设计（Innate Design 民议）→**全路线禁飞升** |
| 民议闸 | `has_civic` | Augmentation Bazaars → 只能义体；进化掠食者/荒野 → 生物系特例 |
| 政策闸 | `has_policy_flag` | AI 政策被禁 → 合成**禁选**（Wiki 权重归 0 同款逻辑）；机器劳工被禁 → 同上 |

闸门全过再谈偏好 —— 社区共识（基因速攻/灵能领袖/合成天花板）只在
「资格允许」的候选集里生效。

**选型决策树（ASCENSION 相位自动执行，先闸后树）**：
0. 过四道闸 → 得到候选集；候选集为空（自然设计等）→ ASCENSION 相位
   只点普通天赋，不选路线；
1. 机械智能 → 机械专属路线（虚拟化/模组化）；
2. 候选含灵能 且（唯心 或 导师起源 或 已有灵能理论）→ 灵能；
3. 候选含合成 且（机械学家起源 或 机器人占比高）→ 合成，AI 政策被禁 → 义体；
4. 候选含生物 → 生物（兽）；起源特例按上表处理；
5. 只剩义体 → 义体。
6. **换线规则**：era2 结束（30 年）时对应关键科技仍不可见 → 在候选集内
   换义体或生物，不许为一条 RNG 路线空等到战力真空（社区致命误区）；
   换线同样重过四道闸。

### 传统树优先级（随年代）

| 年代 | 顺序 | 依据 |
|---|---|---|
| era1（0-10） | 繁荣 → 扩张 → 发现 | 社区共识开局三树：繁荣减建筑成本+采矿站加成；扩张提速殖民；发现提速勘测科研 |
| era2（10-30） | 继续 + 至少完成繁荣全树；解锁第一个飞升天赋 | 飞升天赋需先选 2 个普通天赋节点（Wiki 规则） |
| era3+ | 路线专属树 → 适配军事/经济树 | 专业化期之后传统给战争与巨构服务 |

### 飞升天赋节点查表（当前槽位 → 拿什么）

| 槽位 | 选什么 | 说明 |
|---|---|---|
| 第 1 天赋 | 科技飞升（Tech Ascendancy）或 一体化（One Vision） | 纯增益无副作用，社区默认 |
| 第 2 天赋 | 高效官僚（Executive Vigor）或 帝国 prerogatives | 过渡性经济/凝聚增益 |
| 第 3 天赋 | **路线选型**（按上面决策树） | Wiki：路线天赋要求已选 2 个天赋 + 空传统槽 |
| 第 4 天赋 | 路线第二级（超越/进化精通/合成进化/血肉之躯） | 完成路线核心改造 |
| 第 5 天赋 | 星河奇迹（Galactic Wonders，若已解锁巨构科技）或 巨构类 | 中期滚雪球 |
| 第 6+ 天赋 | 容量/星堡/战争类按 era 查表 | era4 优先舰队容量，era5 优先 Galaxy 守护者（Defender of the Galaxy，危机减伤，社区终局共识） |

**武飞升（危机天赋）特别说明**：Cosmogenesis/星海复仇女神类天赋是独立
的霸道流（第 4 天赋后可选、与守护者互斥、属主题级路线）。本模组缺省
**不自动选**危机天赋 —— 宣战六条件（S-3）管得住战争，但危机天赋会改变
整局胜利目标，属用户级决策，只登记不做。

### 实现落点（S-6）

1. 传统树优先级表：ASCENSION 相位按 `om_era` 查表选下一个传统（替换现在的顺序取用）；
2. 天赋查表：按「当前槽位数 + 已有天赋 + 决策树」选下一个飞升天赋（`add_ascension_perks` 已有调用点）；
3. 换线规则：era3 开始时若路线关键科技不可见则切换备选路线；
4. 危机天赋不进自动查表。
