## 1. 确证 vs 推断

**本节以下全部为「确证」**（每条附证据），除显式标注「推断」者。

### 确证 1 —— 合金门是真的（主根因成立）

`overmind_can_afford` 定义（`common/scripted_triggers/overmind_autonomy_triggers.txt:202-205`）：

```
overmind_can_afford = {
	resource_stockpile_compare = { resource = $RESOURCE$ value >= $PAD$ }
	resource_income_compare = { resource = energy value > 0 }
}
```

存档实读合金库存轨迹（`overmind_metrics.py --trend <桶> --resources`）：

| 年份 | 2228 | 2229 | 2230 | 2231 | 2232 |
|---|---|---|---|---|---|
| alloys | 69 | 30 | 53 | 4 | **50.88** |

⇒ 五档**全部 < 150**，峰值 69。**`PAD = 150` 门在本局从未通过**，且呈锯齿震荡（4–69）
而非累积上行 ⇒ **不是「等积累就会自愈」，是结构性不可达**（见 §4 建议）。

> ⚠️ 该门**无法区分**两个子句：`resource_stockpile_compare`（库存 < 150）与
> `resource_income_compare`（能源收入 ≤ 0）落到**同一个 else 分支**。
> 本局合金库存 < 150 已足以判假，故归因正确；但**判据层面这是精度缺口**（见 §5 建议 R3）。

### 确证 2 —— 容量门「恒假」：`used_starbase_capacity < max_starbase_capacity` 是非法比较式

**代码位置**（5 处，全在同一形态）：

- `mod/stellaris_overmind/common/scripted_effects/overmind_autonomy.txt`
  **L2313 / L2329 / L2369 / L2397**（另 L2363 为注释）

**机制层证据（右侧标识符被解析为「变量」，不是「触发器」）**

原版铁证：`common/buildings/13_fallen_empire_buildings.txt:649-653`

```
	limit = {
		is_variable_set = local_spent_biomass      # ← 先声明它是变量
		any_owned_pop_group = {
			has_trait = trait_wilderness
			pop_group_size > local_spent_biomass   # ← 右侧标识符 = 变量引用
		}
	}
```

⇒ Clausewitz 比较式**右侧只接受字面量或变量**。`max_starbase_capacity` 是**触发器名**，
mod 侧从未 `set_variable` 同名变量 ⇒ 右值解析为 **0** ⇒ `used < 0` ⇒ **对任何 used ≥ 0 恒为假**。

**官方文档层证据**（`logs/script_documentation/triggers.log`）

| 行 | 内容 |
|---|---|
| 2049-2050 | `max_starbase_capacity - Checks the country's max starbase capacity` / 示例 `max_starbase_capacity = 15` |
| 2053-2054 | `used_starbase_capacity_percent - … in relative terms (0.00-1.00)` / 示例 `used_starbase_capacity_percent < 0.75` |
| 3614-3615 | `used_starbase_capacity - Checks … in absolute numbers` / 示例 `used_starbase_capacity = 15` |

⇒ 官方**示例一律「触发器 比较 字面量」**；结构上另有 `_percent` 变体专门供「与上限比」之用。

**原版语料层证据（反证法）**

- 原版 `common/` + `events/` 中 `used_starbase_capacity`（绝对型）**作为触发器使用 = 0 处**；
  唯一实际用法是 **`used_starbase_capacity_percent < 1`**
  （`common/ai_budget/00_alloys_budget.txt:196`；同型见 `00_food_budget.txt:123`、
  `00_influence_budget.txt:285-293` 的 `>= 1 / >= 1.25 / >= 2.0`）。
- 全库检索「触发器名 < 触发器名」形态：命中项**全部是「参数 比较 枚举名」**
  （如 `has_starbase_size >= starbase_starport`、`level >= good`、`value > equivalent`
  —— 右侧均为**枚举 token**，非触发器名）。**零先例**支持 trigger-vs-trigger。

**实机层证据（决定性 —— 与存档真值直接对撞）**

存档实读（自建切片脚本，括号配平解 `country=` 顶层块）：

```
starbase_capacity_used = 1
starbase_capacity      = 5
```

⇒ 若表达式有效，`1 < 5` **必为真**，自报应打「容量有余（未达上限，可升堡）」。
**而实机 26/26 次全打「容量已满（达上限，停止升堡）」** ⇒ **表达式恒假，与真实容量无关。**

> 交叉佐证：`docs/BACKLOG.md` D-48 行 22:3x 独立读数亦为 **`used = 1`**（当时 `capacity = 3`）
> —— 两次读数 used 均为 1，`used < max` 始终成立。**本缺陷不是随容量变化偶发，是稳定恒假。**

**官方 Wiki 层证据（回答 zcode 原问题「outpost 是否占容量」）**

> "The amount of **upgraded starbases** an empire can support is dictated by the Starbase Capacity…
> **Regardless of their level, each starbase bigger than an outpost occupies only one capacity slot**
> and … an empire can always **downgrade existing starbases back to outpost level**."
> —— https://stellaris.paradoxwikis.com/Starbase

⇒ **outpost 不占容量**；`starbase_capacity_used` 只计 outpost 以上级别。
⇒ 代码 L2364 注释「outpost 不占容量、升堡占」**语义正确**，**不是**「门写严」。
⇒ 真正的问题是**表达式写法非法**，与「该不该占容量」无关。

### 确证 4 —— 附带新缺陷：贸易枢纽分支扣费位置错误

`overmind_autonomy.txt:2406-2422`：

```
	random_owned_starbase = {
		limit = { … }
		set_starbase_size = starbase_starport
		set_starbase_module = { slot = 2  module = trading_hub }
		owner = { add_resource = { alloys = -150 } }     # L2418
		log = "OVERMIND: 【贸易枢纽】 … （V-6b，合金 -150 估）"   # L2419
	}                                                     # L2420 ← random 块闭合
	add_resource = { alloys = -50 }                       # L2421 ← ⚠️ 在 if 内、random 外
}                                                         # L2422 ← if 块闭合
```

两处问题：

1. **叠加多扣**：L2418 已扣 150，L2421 再扣 50 ⇒ 实扣 **200**，而注释与自报文案均写「-150 估」
   → **文案与实际不符**（判据失敏同族）。
2. **扣费与效果脱钩**：L2421 **不在 `random_owned_starbase` 内** ⇒ 若该块 `limit` 空匹配
   （无合规目标堡），**不装模块也照扣 50** → 与 **D-48「扣费与效果脱钩」同族**，
   只是量级从 4850 降到 50/次。锚地分支（L2388）**写法正确**（扣费在 random 内）。
