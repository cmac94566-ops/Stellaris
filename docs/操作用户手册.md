# 主脑接管 — 操作手册（给你自己看的）

> 三件事：**开日志窗口**、**开/关 AI 接管**、**读指标**。
> 全程不用控制台，不改存档。

---

## 1. 实时日志窗口（你想看的那个窗）

**双击 `看主脑日志.bat`** 就行。

它会开一个独立的命令行窗口，实时滚动显示主脑在帝国里做的每一个动作。
标题栏写「主脑实时日志」。

### 正常长什么样

```
  主脑实时日志  —  关键字 OVERMIND
  C:\Users\<user>\Documents\Paradox Interactive\Stellaris\logs
============================================================
正在跟 game.log, error.log, system.log, debug.log ...
（先把游戏打开并进入对局；AI 接管后这里会开始滚字）

20:35:14  game   ===== 主脑已接管帝国，自治层上线 =====
20:37:31  game   年度外交回合 —— 已向邻国释放善意
20:40:32  game   【相位 5/8] SCIENCE — 科研与行政
20:40:32  game   建了建筑豪华住宅（building_luxury_residence）于 地球
20:45:48  game   【相位 3/8] JOBS — 岗位与区划铺开
20:47:10  game   建了发电区划（district_generator）于 地球
```

颜色按动作分类：建东西是绿的、接管是紫的、交还是红的、外交是青的。

**灰色行**是每月一次的**相位入口标记**，形如 `【相位 3/8] JOBS — 岗位与区划铺开`。
它不代表"干了活"，只代表"**这个月轮到这一格了**"。配合它下面的动作行读：

| 看到的 | 含义 |
|---|---|
| 灰色相位行，下面跟着动作行 | 轮到了，也真的做了 |
| **只有**灰色相位行，没有动作行 | 轮到了，但条件不满足（通常是资源不够）—— 正常现象，不是故障 |
| 出现**粗体红**的 `【异常】 日程格位越界` | **这个请告诉我** —— 说明法案给的格位值不在 1..8 |

### 几个可以加的开关

| 命令 | 作用 |
|---|---|
| `看主脑日志.bat` | 默认，只跟新内容 |
| `py -3.12 tools\overmind_log_window.py --all` | 把已有内容也倒出来（第一次看建议加） |
| `py -3.12 tools\overmind_log_window.py --list` | **只看现状不进循环**：哪个日志文件多大、有几条主脑记录 |
| `--keyword 别的词` | 换关键字（默认 `OVERMIND`） |
| `--dir <路径>` | 日志目录换地方了才用 |

### 窗口空白怎么办

窗口会每 60 秒打一行「等待中」。如果一直等不到：

1. **游戏进对局了吗** —— 主菜单在主菜单，自治层不会跑。
2. **自治层开着吗** —— 见下一节。默认开局自动接管，但你手动关过就不会自动开。
3. 用 `--list` 看一眼 `game.log` 有没有 `OVERMIND` 命中。有命中但窗口不显示 →
   你是在**启动窗口之前**写的日志，加 `--all` 重开。

> 为什么同时盯 4 个日志文件：游戏把日志分散在 `game.log` / `error.log` /
> `system.log` / `debug.log` 里，而 `log` 这个 effect 的具体落点在写这个工具时
> **尚未实机确证**。已经确认主战场是 `game.log`（本次实机 74 条命中全在这里），
> 但另外三个留着不费什么代价，就都跟了。窗口每行左边会标出来源文件名。

## 2. 开关 AI 接管（你要的"能让它停手"）

**位置：游戏内 → 帝国 → 法令 面板。**

| 法令 | 条件 | 效果 | 花费 |
|---|---|---|---|
| **主脑自治：启用** | 当前未接管 | 自治层上线，开始每月行动 | 1 点凝聚力 |
| **主脑自治：停用** | 当前已接管 | 自治层下线，帝国还给你 | 1 点凝聚力 |

两条法令**同时只会出现一条** —— 没接管时看到的是「启用」，接管后换成「停用」。
点一下即可，不需要控制台、不需要重开游戏、不影响成就之外的东西。

花 1 点凝聚力是故意的：完全免费的法令在游戏里是个异常形态，象征性收一点更自然。

### 什么时候会自动接管

- **开新档**：开局即接管（`overmind.301` 挂在 `on_game_start_country`）。
- **读旧档**：只要没接管、且你没手动停用过，下一个月度脉冲就自动接管
  （`overmind.302`，自愈式启动）。
- **你手动停用过**：不会自动重启，得你自己去法令面板点「启用」。
  （这是设计如此 —— 你叫停就真的停，不做"偷偷又开回来"的事。）

### 接管之后具体会做什么

8 个动作相位轮流跑，每月一格：

| 格位 | 相位 | 干什么 |
|---|---|---|
| 1 | RELIEF | 补真正在赤字的资源（电/矿/粮） |
| 2 | HOUSING | 补住房 |
| 3 | JOBS | 补岗位 |
| 4 | AMENITIES | 补舒适度（娱乐建筑） |
| 5 | SCIENCE | 科研 |
| 6 | MILITARY | 军工姿态（建舰队已改为每月独立执行，不占格位） |
| 7 | ASCENSION | 传统树 / 飞升天赋 |
| 8 | WAR | 战时：陆军、星港、轰炸姿态 |

另外每月固定做两件与格位无关的事：**调姿态**（舰队姿态 + 经济政策）和
**看合金够不够建舰**。每年 1 月额外做一次**外交修补**（不打仗时向邻国示好）。

## 3. 看效果（指标）

```
py -3.12 scripts\overmind_metrics.py --newest
```
读你最新那个自动存档，报出四个指标：区划数 / 建筑数 / 舰队规模 / 传统数。
加 `--json` 出机器可读格式。

游戏默认每 5 年自动存一次（`autosave=5`），所以想看趋势就隔几年跑一次。

## 4. 出问题怎么取证

1. **`--list` 看有没有日志** —— 判断是"没动作"还是"没记录"。
2. **看 `error.log` 有没有 `OVERMIND:` 开头的行** —— 脚本报错都会标出处。
3. **`recursive depth`** 关键字 —— 这是嵌套超限（引擎最多 5 层）。
4. **`is not set for scoped country`** —— trigger 名字写错或引擎没实现。

把 `error.log` 里带 `overmind_autonomy` 的行发我即可，路径都带行号。

## 5. 已知限制（先知道，免得当成 bug 查）

| 现象 | 说明 |
|---|---|
| ~~日志只记"做成了的事"~~ | ✅ **已修**：每个相位入口现在都有一条灰色无条件标记，所以"轮到了但干不了"和"压根没轮到"在日志里能分开了。**此修复需重启游戏才生效** |
| **人格层是失效的** | 游戏不允许中途改国家人格，所以主脑的控制力来自静态修正 + 政策切换，不是"换了个 AI 人格" |
| **不碰战争目标/舰船设计** | 目前只会建舰队、调姿态、造陆军星港。宣战与定制舰船设计在 M3 |
| **传统相位可能长期不动** | 传统要凝聚力付费，早期帝国凝聚力紧张时会一直跳过 |
| **改脚本必须完全退出游戏** | Clausewitz 不热重载 mod 脚本。改完重进才生效 |
