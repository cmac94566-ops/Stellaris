# V-1 科技力优先级 —— 机制取证与规格

> **立项依据**：科技力 = 胜利分数 **99.8%**（`docs/胜利路线图.md:43/52`，实测本局 927 800 × 0.25 = 231 950）。
> V-1 是 V 系列**最高优先级**项，且此前**既无能力、也无规格** —— 本批补齐后者。
> **版本基准**：本机 Pegasus **v4.4.6**（`D:/SteamLibrary/steamapps/common/Stellaris`）。
> 下文数值一律以**本机语料**为准；Wiki / 社区旧值单独标注"过时"。
> **属地**：本文属 WorkBuddy（规格 / 验收 / 取证）。**产品代码由 zcode 实现**，本文不含代码改动。

## 0. TL;DR（五条）

1. **零能力确认**：`building_institute` / 三个专业研究建筑 / `col_research` / `research_subsidies` /
   `add_edict` / `add_tech_progress` 在 `mod/stellaris_overmind/**` **全部 0 命中**。
   现役研究能力只有 **`zone_research`**（`overmind_autonomy.txt:432/443`）与
   **`building_research_lab_1`**（`:612/618`）—— 即"只堆产能"，与 BACKLOG V-1 行描述一致。
2. **命名陷阱（D-8 第 N 次）**：规格书与社区都叫 "Research Institute"，本机**真实 id = `building_institute`**
   （`building_research_institute` **全库 0 命中**）；Wiki 标注的解锁科技 "Interplanetary Research Initiative"
   本机**零命中**，真实 key = **`tech_global_research_initiative`**。
   ⇒ **凡直接照抄社区名字写 `add_building` 的，会静默失败**（与 D-39 / V-6c 同族）。
3. **数值大面积过期**：路线图 §9.3 的三条社区数值中**两条是 3.x 旧值** ——
   研究所"研究员产出 **+15%**"在 4.4.6 实为**逐系直产 `+0.5`**（不是百分比）；研究协议"**+25%**"是
   **科技成本 −25%** 而非研究速度。（"首席科学家 −25%"这条**反而是对的**，见 §2。）
4. **两条硬边界，不得假装实现**：
   ① **科研区首席科学家指派无任何脚本接口**（`effects.log` 全文无 `research_area` 相关 effect；
   `assign_leader` 支持 country scope 但语义未确证）⇒ `TECH_RESEARCH_NO_LEADER_PENALTY = -0.25`
   这一项**当前不可脚本修复**；
   ② **研究协议无 effect**（只有 `has_research_agreement` / `num_research_agreements` 两个**触发器**）⇒ 无法脚本发起。
5. **一条正面发现（本轮最大产出）**：**法令（edict）可脚本激活** ——
   `add_edict`（`script_documentation/effects.log:3265`）是合法效果，且原版给出
   「**补足成本 → 激活 → 清余**」的**完整范式**（`events/shroud_events.txt:925-945`），
   证明**成本真实扣除、不是白拿**。⇒ `research_subsidies`（研究补贴，`+0.10` 研究员岗位系数）
   可**正规接入**，不需要自造修正，也不需要 A4 让步。

## 3. 规格（R0–R7，按序落地，**一次只动一个变量**）

### R0 — 目标集与硬门（**复刻引擎门，禁止自设更严**）
- 研究所：门 = **`has_technology = tech_global_research_initiative`** ∧ `NOT = { has_building = building_institute }`
  ∧ 星球满足其 `potential`（非度假/奴隶/流放球 ∧ `owner = { is_regular_empire = yes }`）。
- 专业建筑三选一：门 = 对应 `tech_physics_1` / `tech_society_1` / `tech_engineering_1` ∧ `NOT = { has_building = … }`。
- **凡引擎门未要求的条件（如"首都""人口数""产出结构"）一律不得加** —— 加门即制造 D-39 型静默失败。
- **scope 要求**：`has_building` / `add_building` 均在 **planet** scope；科技与 `is_regular_empire` 需
  `owner = { … }` 切换（**不得**在 planet scope 直调 country 触发器）。

### R1 — 研究所（主目标，收益最大）
- 动作：`add_building = building_institute`（planet scope），**扣费先于动作**：
  `owner = { overmind_can_afford_* }` → `overmind_charge_building_building_institute` → `add_building`。
- **幂等**：`NOT = { has_building = building_institute }` **实时查，零账本**（铁律 20）。
- 选点：优先**已有 `zone_research` 且人口最多**的球；**不用随机**（避免"建在无人球上"，与 D-25 教训同族）。

### R2 — 专业研究建筑（按星球现有产出结构择一）
- 映射：球上**已建** `building_research_lab_*` 的系别占比最高者 → 对应专业建筑；
  无法判定时**默认工程**（`engineering_facility`，社区共识工程消耗最大）。
- 判据只能读**已有建筑/岗位**（`has_building` / `num_assigned_jobs`），**不得读"计划产出"**。

### R3 — 研究世界专精（**复用 V-7，不重写**）
- 直接调用 V-7 R1 的映射条目 `col_research`；**V-1 只负责"选哪些球"**（产出结构 + 非首都 + 非环形/栖息地）。
- 冲突裁定：**专精写入以 V-7 为唯一实现**，V-1 不做第二套 `set_colony_type` 调用点。

### R4 — 研究补贴法令（**新通道，建议先做小样验证**）
- 动作序列**照抄原版范式**（`shroud_events.txt:925-945`）：
  `add_resource unity += 成本` → `add_edict = research_subsidies` → 清余量（`export_resource_stockpile_to_variable`
  + `add_resource = { unity = -1 mult = <余量变量> }`）。
- **门**：`has_tradition = tr_discovery_databank_uplinks` ∧ `NOT = { has_edict = research_subsidies }` ∧ 统一库存充足。
- ⚠️ **待确认**：`multiplier = value:edict_size_effect` 是**规模相关动态倍率**，`engine/cost_table.py`
  当前是否能解析 `multiplier` **未验证** ⇒ 若不能，须**先扩生成器**，**禁止**回退成手写近似值。
- ⚠️ 本项是全规格**唯一"给钱办事"的负收益动作**（统一是稀缺资源）⇒ 应由 **`om_era` ≥ 3** 才启用（年代阈值查 `om_era`）。

### R5 — 接入点：**挂 tick 直调段，不挂相位**
- 与 **V-7 R4 同层**（tick 直调段）。理由：相位通道受 S-18 规则集 + 熔断支配，
  会导致 **D-39 型"零执行"** 与 **D-40/D-41 型"熔断饿死"**（历史两次踩坑）。
- **effect 嵌套预算**：tick(1) → `every_owned_planet`(2) → 条件/动作(3)，**≤5 层**，不越第 6 层。

### R6 — 日志与降噪
- 标签一律**全角【】**（铁律 15/纪律：禁 ASCII 方括号）；建议 `【研究】研究所` / `【研究】专业建筑` / `【研究】补贴法令`。
- **动作谓词锚定**：统计时按"星堡补/研究落成"这类**动作短语**过滤，**不得**用标签自污染数字
  （D-48 轮次教训：诊断文案内嵌字面量曾使 `grep -c` 得 194 而真值 97）。
- 每月每动作**各一次**（独立 `om_did_*` 标记），**禁止**逐月重复打印同一动作。

### R7 — 明确不做
1. **科研区首席科学家指派**（无接口，§1.5）；
2. **研究协议**（无 effect，§1.5）；
3. **`give_technology` / 白送 `add_tech_progress`**（违 A4）；
4. **自造研究速度修正**（`add_modifier` 手搓 `research_speed`）—— 原版已有法令/传统/飞升三条正规通道，
   自造修正会**污染存档兼容性**且无法被玩家复核。

## 4. 验收标准（AC-1..AC-8，**一律锚定状态，不锚定声明**）

| # | 判据 | 观测方法 | 通过条件 |
|---|---|---|---|
| **AC-1** | 研究所**真的落盘** | 存档逐球读 `buildings` 含 `building_institute` | 命中球数 ≥ 1 且 **≥ 合格球数的 50%**（排除"没科技"的球） |
| **AC-2** | 专业建筑落盘 | 同上，读三个 id | 每系至少 1 处落地 |
| **AC-3** | 专精生效 | 存档 `has_designation = col_research` 可读 | ≥1 球（与 **V-7 AC 联检**，两规格结论必须一致） |
