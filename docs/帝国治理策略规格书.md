## 1. 总原则（七条）

| # | 原则 | 一句话解释 |
|---|---|---|
| P1 | **发展优先** | 前期合金是扩张命脉，舰队只求吓阻；科研/殖民地/经济铺开前零扩军 |
| P2 | **资源冗余** | 任何花销动作不得打穿安全垫；能源月收入为正是底线（赤字扩军 = 社区公认崩溃起点） |
| P3 | **冗余不等于囤积** | 安全垫之上的富余合金要花出去（社区：「囤着 1000 合金不用 = 已经输了」）—— 花在主动扩张白名单上 |
| P4 | **比例控制** | 舰队规模对齐海军容量，不超容（超容维护惩罚重）；民生建筑对齐岗位缺口，不空转 |
| P5 | **年代分期** | 不同年代做不同事（§2），阈值随年代调整，不是一套常数跑到底 |
| P6 | **威胁分级响应** | 和平期守 P1-P4；威胁升高时豁免部分限制，但**容量门与能源门永不豁免** |
| P7 | **规则优先于计划** | 输出的必须是**判断规则**（什么条件做什么），不是**时序计划**（第几月做什么）。决策在运行时用实时局势求值 ⇒ 局势变则决策变，不失效。（架构公理 A1，见《月度干预架构规格_决策规则求值》§0） |

## 2. 年代分期（引擎时间轴）

| 年代 | 名称 | 经济目标 | 军事目标 | 相位侧重 |
|---|---|---|---|---|
| 0-10 年 | **发展期** | 铺区划补基础收支；科研建筑起步；殖民地船 | **零扩军**（已实现：`years_passed >= 10` 门） | JOBS/SCIENCE 优先，WAR 相位只做哨站维护 |
| 10-30 年 | **巩固期** | 专业化分工：铸造星/研究星；合金月收入爬坡 | 吓阻舰队：容量 30-60%，15-40 护卫舰，停边境咽喉 | AMENITIES 补舒适度；MILITARY 开始建舰 |
| 30-75 年 | **专业化期** | 铸造世界成型（社区目标：约 20 年 +50 合金/月）；贸易值转化能源 | 容量 60-90%；驱逐舰/巡洋舰换代 | WAR 相位开始评估宣战（§5） |
| 75-150 年 | **扩张期** | 多星系纵深；传统树推进 | 满容量常备军；首场有限战争（§5 条件） | MILITARY/ASCENSION 并重 |
| 150 年+ | **危机准备期** | 经济支撑多支满编主力舰队 | 战列舰为主力编成；咽喉星垒要塞化 | WAR 侧重防御建设 |

## 3. 资源冗余线（硬约束，所有花销动作共用）

| 资源 | 安全垫（库存底线） | 收入门 | 说明 |
|---|---|---|---|
| 合金 | **≥ 300**（造舰后剩 200+） | — | 造舰/哨站共用；威胁 ≥3 时降到 50 |
| 能源 | — | **月收入 > 0** | 舰队与建筑维护都吃能源；收入 ≤0 时冻结一切扩军动作 |
| 消费品 | ≥ 50 | 收入 ≤0 时不建科研建筑 | 消费品喂科研，赤字会断研究 |
| 食物 | ≥ 50 | 收入 ≤0 时停殖民 | 防饥荒 |
| 矿物 | ≥ 200 | — | 区划/建筑的原材料 |

**实现方式**：新建 scripted_trigger `overmind_can_afford = { RESOURCE = x PAD = n }`（库存 ≥ 垫 + 收入门可选），全部花销动作统一走它 —— 替换现在散落的单点 `resource_stockpile_compare`。

## 4. 建舰与军事策略

### 4.1 建舰四门（✅ 已实现，`overmind_autonomy_build_ship`）

1. 容量门：`used_naval_capacity_percent < 1.0`（D-20，原版 ai_budget 同款）
2. 发展优先门：`years_passed >= 10`，威胁 ≥3 豁免
3. 能源门：`resource_income_compare = { resource = energy value > 0 }`
4. 冗余门：合金 ≥ 300（威胁 ≥3 时 ≥ 50）

### 4.2 舰队规模目标（待实现，按年代）

| 年代 | 容量使用率目标 | 依据 |
|---|---|---|
| 10-30 年 | 30-60% | 吓阻海盗与冒进邻居即可，别为海军牺牲科研（「15 年 20 艘护卫舰 = 没科研」社区教训） |
| 30-75 年 | 60-90% | 邻居来时应有 30-40 护卫舰级战力 |
| 75 年+ | 90-100% | 满容量常备军，为有限战争与危机准备 |

**实现**：MILITARY 相位按年代比较「当前容量使用率」与目标，不足才触发建舰 —— 建舰从「每月能造就造」改为「向年代目标补齐」。

### 4.3 宣战条件（WAR 相位，待实现，全部满足才宣战）

1. `years_passed >= 30`（专业化期之后）
2. 目标国相对军力 < 我方 70%（情报触发器 `relative_power` / `fleet_size` 对比）
3. 我方能源与合金月收入均为正、库存达安全垫
4. 目标国**不在联邦**或其联邦不在战争状态（社区教训：中期动一个，联邦全反目）
5. 战争目标限于割取边境数系或逼附庸，不打灭国战
6. 威胁 ≥3 或对方已宣战时豁免 1、3 的库存条

### 4.4 编成（远期，M2+）

护卫舰（导弹+炮混编）→ 巡洋舰（旋风导弹大侧舷 70% + 混编 30%）→ 战列舰（炮舰/航母分队）。编成属于造船设计器范畴，先行登记，暂不实现。

## 5. 经济相位策略（反应式为主 + 白名单式主动扩张）

这是 D-13 决策 A 的落地边界：**健康帝国允许平台期**，但冗余资源不能躺着 —— 花，只花在白名单上。

| 优先级 | 主动扩张动作 | 触发条件 | 相位 |
|---|---|---|---|
| 1 | 研究区（zone_research） | 消费品收入 > 0 且库存 ≥ 垫 | SCIENCE |
| 2 | 铸造区（zone_foundry） | 矿物收入 > 0 且合金收入 < 社区爬坡线 | JOBS |
| 3 | 贸易区（zone_trade） | 能源收入 < 需求爬坡（贸易值=白嫖能源，社区共识） | JOBS |
| 4 | 城市区划（district_city） | 住房余量 < 2 且该星未达城区上限 | HOUSING |
| 5 | 殖民（远期） | 有可殖民星且食物/能源达垫 | WAR/独立判定 |

**仍保留的反应式底线**：任何赤字（能源/食物/消费品/住房/岗位/舒适度）出现时，对应相位动作**优先于**一切白名单扩张。

## 6. 威胁评估（om_lex_threat 的构成，待实现）

现状：`om_lex_threat` 是静态值（D-16），法案手写。成熟化方案 —— 由 tick 每年重算：

| 分量 | 权重 | 判定 |
|---|---|---|
| 最强邻国军力比 | 0.4 | 邻国军力 > 我方 80% → +1；> 120% → +2 |
| 处于战争 | 0.3 | 被宣战 +2，主动宣战 +1 |
| 宿敌/清洗者邻接 | 0.2 | +1 |
| 危机年代 | 0.1 | 中期危机后 +1 |

0-5 分级不变（≥3 走威胁例外）。这一步把「策略」从写死的阈值变成随局势自调节的闭环。

## 8. 与验收标准的关系

- AC-4 v2（终值不降 + 无持续下降段 + 冻结标注意）与 P3「冗余要花出去」自洽：主动扩张白名单正是让健康帝国的区划/建筑**继续有理由增长**的机制，缓解「平台期」观感。
- F3' 重测协议不变：重开一局、【相位】+【归因OK】心跳、零【告警】、303 加速器快进 12 年。
- 本策略涉及的行为变化全部要过既有守卫（嵌套深度 ≤5、括号平衡、注入反向验证）。
