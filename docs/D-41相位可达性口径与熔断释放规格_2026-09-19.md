读数三点：

1. **p1 = 222 → 0：R0 存量自愈生效** ✅ ⇒ **对账 #19「streak 活性」可判「通过」**

3. **`om_lex_gain_p1..p8` 在 2214 档全为 0** ⇒ 熔断门的释放条件「**有正收益**」恒不满足。

### 2.4 归因（确证 / 推断分级）

**确证**
- D-40 的 R0/R4/R5 **已生效**（p1 自愈、回填 195→1、熔断 117→4、`【议程】` 可见）。
- 相位 6/7/8 = 0 在本局**由规则条件决定**（§1.2 规则表 + 2210 era 断点双证）。
- 熔断标志 p2/p3/p4/p5 **整个 24 年未清除**，`【熔断解除】` **0 次**。

**推断（请 zcode 复核）**
- 释放通道失效的**直接原因**是「仅有正收益才清标志」这一单一释放条件；
  在增益读数恒 0 的局里该条件**恒假**，于是标志成为**一次写入、永不回收**的状态。
- **R2 半开探测确实在跑**（相位 3/5 各 69 次 ≈ 4 次/年/相位，与「探测月重置 streak →
  重新累积 3 月 → 再熔断」的 3 月周期吻合），所以 D-40 的活锁**已从「永久停摆」
  缓解为「降级运行」**；但**并行 3 槽从未兑现为稳定产能**。

## 3. 规格（D-41 修法，R0–R4，按序一次只动一个变量）

| 编号 | 修法 | 说明 |
|---|---|---|
| **R0** | **释放条件扩展（本修核心）** | 除「有正收益」外，新增 **「探测月执行成功即释放」**：探测月放行后**无条件清 `om_fused_pN` 并把 streak 归零**。理由：探测路径的存在意义就是「暂停可自愈」；若探测成功后仍不释放，探测就只是降级而非自愈。 |
| **R1** | **探测月由既有变量派生** | 用现成 `om_month`（8 槽月轮，探针已实测存在且可取 8）或 `om_probe_rot` 派生，**不得新造账本**（铁律 20）。 |
| **R2** | **标志与 streak 一致性守卫** | 每次 tick 末：`om_fused_pN = 1` **且** `streak < 3` ⇒ 强制清标志。一次即可覆盖 §2.2 的「标志=1 而 streak=0」不一致。 |
| **R3** | **探测路径可观测** | 探测月实际执行时补一行全角标签 `【探测】相位 N/8`（与 `【相位 N/8】` 并存）。**不得只加日志不加逻辑**（铁律 20）；此标签是 AC-4 的唯一锚点。 |
| **R4** | **降噪续做** | `【熔断汇总】` 80 行/24 年仍偏多 ⇒ 放宽到 **24 月一行**，并只在「相位集合有变化」时打行。 |

**约束（沿用，逐条核对）**：5 层 effect 预算 · 日志一律全角 `【】`（禁 ASCII 方括号）·
花销走 `overmind_can_afford` · 年代阈值查 `om_era` · 引用触发器/效果注明 scope 要求 ·
**不自造账本、不写空壳日志** · **回填区禁 streak 门的守卫不得删**（`702b9a2`）。
