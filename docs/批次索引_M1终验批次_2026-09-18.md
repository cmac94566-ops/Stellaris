## 五、本批方法论沉淀（新增铁律）

| 铁律 | 内容 | 反例 |
|---|---|---|
| 15 | bat 文件禁非 ASCII 字符 | 中文 `REM` 被 cmd 按 GBK 逐字节解析 ⇒ `REM` 失效 ⇒ 报「不是内部命令」 |
| 16 | **协议/格式变更必须盘点依赖方**（文件头口径 / 各方解析脚本 / 协议文档） | 前缀改 `WDMSG-` 而口径与对方脚本未动 ⇒ **19 小时漏读 13 条** |
| 17 | 本机取证只证「存在」，**不证语义**；否定性结论必须写明检索范围 | `is_colonizable` 语义误判；三项议程效果被误判「已弃用」（只搜 `common/` 漏 `events/`） |
| 18 | 统计/趋势前先验**样本同一性与连续性** | M1 误把异局档算入 ⇒ 误判「不通过」 |
| 19 | 采集类故障**先查路径再查频率** | 「丢年份」原判「扫得太慢」，真因是守望器**从未扫云存档目录** |
| 20 | **不自造账本，不写空壳日志** | `om_leader_count` 无初始化；`assign_leader` 段只有一行 log |
| 21 | 双方共仓提交一律**定向** `git add <文件>`，**禁用 `-A`** | `git add -A` 卷走对方在途文件；收尾记录被并发实例覆盖 |
| 22 | 协议必须**单一真相源**，禁止在别处重写取号逻辑 | `notify_zcode` 自建第二套取号未排除 900+ 保留段 ⇒ 误编 `WDMSG-901` |

**核心一句**：**「口径说明本身也是代码」** —— 别人会照抄它。
