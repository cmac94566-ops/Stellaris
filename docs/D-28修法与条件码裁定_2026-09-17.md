## 3. 能源满仓裁定：不采用「垫减半」，也不采用「观望」

### 3.1 为什么否掉两个候选

- **「能源 ≥ 5000 时矿物垫减半」——否**：① 把"防负债垫"交给另一个资源的脸色决定，**耦合两类风险**；② 能源满仓**不代表矿物可支配**（本局矿物 163→88，正是最穷的时候）；③ 5000 与本局实测 25000 封顶毫无数量关系，是拍脑袋数。
- **「登记 P3 违规观望」——否**：把已知违规挂着不动 = 默认接受，且 P3「冗余不等于囤积」本项目已写进规格书。
- **自建兑换（`add_resource` 负值："扣 25000 能源换 X 矿物"）——明确不做**：会给 mod 引入自成体系的汇率与经济，与"复用原版机制"的项目原则冲突，且平衡口径无依据。若日后要做，须总裁席单独立项。

### 3.2 采用方案：满仓感知 + 方向切换（两件套）

1. **条件码 17 / 18**（§4）作为满仓判据 —— 能源 / 食物 ≥ **存储上限 90%**。
2. **命中即切换方向**：
   - 能源 ≥90% ⇒ **当期停建** `district_generator` / `zone_energy`，把配额转投**耗能产能**：`zone_industrial`（双产，见 §5）、`zone_research`，以及对应产能建筑；
   - 食物 ≥90% ⇒ **当期停建** `district_farming` / `zone_food`；
   - 停建与转投**同一条规则内完成**（顺序即优先级），不外挂第二个判据。
3. 语义：把 P3 落成"**不往已经溢出的方向继续堆，把配额转到缺的方向**"，而不是"凭空把能源换成矿物"。
