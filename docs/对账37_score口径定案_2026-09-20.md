## 3. #38 / D-52 失败项 —— 「名次」不是名次

### 3.1 决定性证据（同档内自相矛盾）

**（a）140/150 国共用同一个 `victory_rank` 值**，而这些国家的分数互不相同：

```
[rank] 不同名次值 = 11  并列的名次值 = 1  并列涉及国家数 = 140
        名次 180 有 140 国，分数 [2907.5, 5050.0, 5063.125, 5071.875, 5110.395, 5111.375, …]
```

**（b）名次值集合严重缺号**：2254 档出现的 rank 值只有 **2,3,4,5,6,7,8,14,29,30,180** 共 11 个
⇒ **缺 1、9–13、15–28、31–179**。

**（c）rank 字段与分数序直接冲突**：

| 国家 | `victory_score` | `victory_rank` |
|---|---|---|
| 24 | 76,956 | 2 |
| 190 | **23,249** | **180** |
| 17 | 3,937 | 14 |
| 0（主脑） | **867** | **29** |
| 111 | 836 | 30 |

⇒ 23,249 分得 180 名，而 867 分得 29 名：**字段序 ≠ 分数序**。

**（d）按分数的真实位序**

```
2254 档：主脑 score=866.76  rank字段=29  真实按分数位序=149/150
2231 档：主脑 score=905.90  rank字段=28  真实按分数位序=158/158
```

⇒ 主脑**按分数是银河倒数第一/第二**；`--score` 打印的「名次 29/150」把这一差距**读成了中游**。

### 3.2 语义查证（铁律 17：先官方/社区，再本机）

- **本机**：`common/defines/` 全库检索 `VICTORY_RANK` / `victory_rank` ⇒ **0 命中**
  （检索范围：`D:/SteamLibrary/steamapps/common/Stellaris/common/defines/*.txt`，含 `00_defines.txt`）。
- **社区**：Wiki《Empire》/《胜利条件》（群星中文维基 v4.3）**只描述胜利分数的构成**
  （经济实力 / 科技等级 / 帝国规模 +10 系统 +50 殖民地 +0.02 人口 / 外交 / 危机 / 遗珍），
  **未描述存档 `victory_rank` 字段**。
- ⇒ **字段语义为"未查证"**（不作"是哨兵值 / 是未排名"之类的断言）。
  但 §3.1 的内部矛盾属**观察级事实**，**足以判定"不可用作名次"**，无需依赖语义假设。

### 3.3 附带：连"哨兵值恒定"也不成立

2254 档填充值 = **180**，2231 档填充值 = **186**（两档国家数 150 / 158）
⇒ 与「固定哨兵」假设不符，**用差值法反推名次亦不可行**。
